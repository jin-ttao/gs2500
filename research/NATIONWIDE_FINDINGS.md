## 품질 점검

- 후보의 상가업소번호 중복: **0그룹**.
- 정규화한 도로명주소(없으면 지번주소) 중복: **521그룹, 1,102개 기록**. 같은 건물 내 여러 점포일 수 있으므로 병합하지 않았다.
- 후보의 주소/상가업소번호 누락: **0건**.
- 후보의 좌표 누락·숫자 형식 오류·근사 한국 영역 밖 좌표: **각 0건**. 정확한 점포 건물에 찍혔는지를 검증했다는 뜻은 아니다.
- 재검토 사유는 중복될 수 있다: 비편의점 소분류 284건, 표준산업분류 충돌 255건, `25` 없는 약한 GS 명칭 252건, 명칭 위치 불명확 148건, 브랜드 뒤 숫자 충돌 8건.
- 자동 테스트 **13개 통과**. 실제 전국 원본의 모든 행 처리 합계와 후보 분류 합계가 일치한다. ZIP의 한글 파일명은 CRC 검증된 Unicode Path 메타데이터로 해석하고 원본 파일명 바이트도 보존했다.

## 공식 사이트 대조: 삼성역점 1건

- 공식 표시: `GS25삼성역점`, `서울 강남구 영동대로510, 1층(삼성1동 168)`.
- 공공 원본: 상호 `GS25`, 지점명 `삼성역점`, `서울특별시 강남구 영동대로 510`.
- 소스 ID: `MA010120220801045683`, 서울 CSV 기록/물리 행 241861.
- 원본 좌표: 경도 `127.062852736565`, 위도 `37.5105419476433`.
- 공식 표시 서비스: 상비의약품, 현금출금, 군고구마, 반값택배픽업, 붕어빵, 마감할인.

명칭·주소가 연결되는 **한 건의 대조**이다. 표본 1개로 전체 추출의 정확도/재현율을 추정하지 않는다. 서비스 목록의 완전성, 영업시간, 실제 내부 구조, 방문자 구성, POS 판매는 미확인이다. 기존 합성 삼성역 데모는 이 실제 점포를 실측 복제한 것이 아니다.

## 무엇을 확보했고, 무엇이 남았나

확보한 것은 **전국 스냅샷 기반 후보 목록, 지역 분포, 소스 행까지 추적 가능한 원문, 품질 검사, 공식 점포 조회 표본**이다.

아직 남은 것은 공식 전점 명부와의 대조, 재검토 913건 처리, 이름에 GS25가 없는 누락 후보 조사, 상권/서비스 연결, 대표 점포의 도면·진열·POS 확보다. 따라서 ‘전국 모든 GS25 조사를 끝냈다’ 또는 ‘전국 실제 매출을 예측할 수 있다’고 말하지 않는다.

다음 구현의 데이터 기반:

1. 이 모집단 위에 서비스·상권·기준일별 근거를 연결한다.
2. 일반점과 특화점이 모두 포함되도록 실측 표본을 고른다.
3. 실제 평면·재고·가격·행사·시간별 방문 자료가 있는 점포부터 파라미터를 보정한다.
4. JEV에는 이 근거와 **현재 위치에서 관찰 가능한 상품/행동**을 전달한다. 생성된 페르소나의 그럴듯한 스토리를 실제 고객 통계로 취급하지 않는다.
