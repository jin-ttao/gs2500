# GS2500 — 동시 3D 매장 실험실

합성 점포 9곳 × 진열 후보 4개를 **36개의 실제 3D 세계**에서 비교하는 해커톤 데모입니다.
데스크톱에서는 점포 4곳을 2×2로, 각 점포의 후보 4개도 2×2로 묶어 한 페이지에 16개 카드를 보여줍니다.
전체 점포는 4곳 / 4곳 / 1곳의 세 페이지이며, 보이지 않는 점포도 같은 시계로 계속 실행됩니다.
각 카드의 고객 이동·상품 선택·집기·결제·퇴장은 하나의 시뮬레이션 엔진에서 진행되고,
카드의 재고·매출·매출총이익도 같은 사건에서 계산됩니다.

실제 GS 내부 데이터, 고객 개인정보, 실제 매출 예측을 사용하는 서비스가 아닙니다.
GS와의 공식 제휴·승인을 의미하지 않습니다. JEV·Nemotron·외부 추천 API는 연결하지 않았습니다.

## 실행

필요 환경: Node.js 22 이상과 npm, Python 3, WebGL을 지원하는 브라우저.
저장소 루트에서 실행합니다.

```bash
cd demo
npm ci
npm test
npm start
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)을 엽니다. API 키나 유료 서비스는 필요 없습니다.
이미 설치한 의존성은 `npm start`만으로 실행할 수 있습니다.

## 데모 흐름

1. **전체 실험 시작**: 본사 표준안 / 재고 우선안 / 균형 후보안 / 신상품 탐색안을 아홉 점포에서 함께 실행합니다.
   터치·트랙패드의 좌우 스와이프, 마우스 드래그, 이전·다음 버튼 또는 페이지 점으로 다른 점포를 봅니다.
   모바일은 점포마다 후보 4개의 2×2 구성을 유지하고, 점포 묶음을 세로로 쌓습니다.
2. **하루·배속·정지**: 점포당 잠재 고객 1,000명의 하루를 00:00–24:00까지 비교합니다.
   입장하지 않는 사람도 집계하며, 기본 4×입니다. UI의 1 / 4 / 16 / 32 / 128 / 900× 설정이
   이동·판단·보충·애니메이션·집계에 함께 적용됩니다. 카드 모션만 따로 늦추지 않습니다.
   처리 성능이 부족하면 실효 배속을 표시하며, 숫자만 앞서 계산하지 않습니다.
3. **카드 확대**: 실제 진행 중인 세계를 확대합니다. 닫기 또는 Escape로 전체 화면에 돌아옵니다.
4. **후보 비교**: 모의 결제액, 합성 원가를 뺀 매출총이익, 품절로 실패한 구매 시도를 봅니다.
5. **계획 승인**: 해당 후보의 24시간 실험이 끝나면 계획을 저장할 수 있습니다.
   점주 보기에는 승인한 스냅샷만 표시합니다. 저장은 이 브라우저의 localStorage이며 실제 인증·발주가 아닙니다.

같은 점포의 후보는 같은 초기 총재고·시드·잠재 고객 일정을 사용합니다.
매대 재고와 창고 재고는 별도이며, 보충 직원이 이동·진열을 마친 뒤 보유 물량만 매대로 옮깁니다.
계산원과 보충 담당자는 별도 인력이라는 데모 가정입니다. 자동 발주나 무한 재입고는 없습니다.
공간 혼잡·입장 거절·체류 시간·보충 지연은 후보별로 달라질 수 있습니다.
완료 전 매출만으로 우승 후보를 확정하지 않습니다.
4×는 동작 관찰용으로, 24시간의 산술상 실행 시간은 6시간입니다. 빠른 하루 비교용 900×는
산술상 96초이며, 실제 완료 시간은 계산·렌더링 성능에 따라 더 길 수 있습니다.

## 정적 배포용 파일

```bash
cd demo
npm ci
npm run build
npm run preview
```

`demo/dist`에 필요한 소스·에셋·Three.js 런타임을 복사합니다.
미리보기는 [http://127.0.0.1:4174](http://127.0.0.1:4174)입니다.
`dist` 내용만 정적 호스팅에 올릴 수 있으며, 빌드 과정은 실제 배포나 외부 API 호출을 수행하지 않습니다.
저장소 루트의 `index.html`은 기존 배포 연결 확인용 임시 페이지를 보존한 것입니다.

## 범위와 공개 파일

현재는 가상 상품 24개, 수작업 페르소나 유형 5개를 사용하는 로컬 규칙 모델입니다.
전국 점포 기초조사는 [research/README.md](research/README.md)에 별도로 기록합니다.
실제 전국 점포 구조를 복제한 모델은 아니며, JEV 실호출도 아직 연결하지 않았습니다.
24시간 동안 잠재 고객 1,000명의 입장 여부를 평가하지만 시간대별 유동인구·입점률은 합성 가정입니다.
실제 수요로 보정한 매출 예측이나 실제 POS 매출이 아닙니다. 각 점포의 A/B/C/D는 같은 1,000명을
다른 배치로 재실험하므로 36개 카드의 사람 수를 합쳐 36,000명의 독립 고객이라고 해석하지 않습니다.
신상품 탐색안(D, 보라색)은 가상 신상품 5종을 함께 배치한 비교안이며, 우승 결과를 강제로 만들지 않습니다.
Smallville의 기억 검색·반성 루프, 실제 GS 추천 역추정, 신상품 자동 발주, 서버 인증은 구현 범위 밖입니다.

API 키·환경 파일·의존성 폴더·로컬 기획 노트는 공개하지 않습니다.
`demo/server.mjs`는 미통합 로컬 수동 검토 프로토타입입니다. 기본 실행·정적 빌드에 사용하지
않으며 JEV 평가 API 구현이 아닙니다. 명시적인 키와 모델 설정 없이는 API를 호출하지 않고,
JEV를 Chat Completions로 보내거나 GPT로 자동 대체하지 않습니다. 안전성 검사는
`cd demo && node --test server.test.js`로 실행하며 실제 외부 API는 호출하지 않습니다.
Blender 편집 파일은 로컬 메타데이터를 포함할 수 있어 제외하고, 재생성용 Python 스크립트와
런타임 GLB를 제공합니다. 생성된 상품 포장은 가상 상품이며 공식 GS 상품 이미지가 아닙니다.

Three.js는 MIT 라이선스 의존성입니다. 자체 코드에 별도 오픈소스 라이선스를 추가하지 않았으며,
이 저장소를 공개한 것만으로 GS의 상표·상품 이미지에 대한 권한이 부여되는 것은 아닙니다.
