# GS2500 — 동시 3D 매장 실험실

합성 점포 9곳 × 진열 후보 4개를 **36개의 실제 3D 세계**에서 비교하는 해커톤 데모입니다.
점포마다 후보 4개를 2×2로 묶습니다. 카드는 참고 이미지의 세로 비율을 유지하며,
16개를 한 화면 높이에 압축하지 않습니다. 화면 폭에 따라 점포를 1~2열로 배치하고 아래로 스크롤합니다.
전체 점포는 4곳 / 4곳 / 1곳의 세 페이지입니다.
기본 **빠른 비교**는 원본 24시간 계산을 먼저 완료한 뒤 최대 12명의 실제 방문을 겹쳐 재생합니다.
최초 계산 시간은 별도 표시하고, 다시 보기는 메모리에 준비된 기록을 재사용합니다.
실제 동시 방문 영상이 아니며, 재생 속도·체류 연출로 매출·재고·구매 결과를 바꾸지 않습니다.
**실시간 관찰**에서는 보이지 않는 점포도 같은 시계로 계속 실행됩니다.
각 카드의 고객 이동·상품 선택·집기·결제·퇴장은 하나의 시뮬레이션 엔진에서 진행되고,
카드의 재고·매출·매출총이익도 같은 사건에서 계산됩니다.

실제 GS 내부 데이터, 고객 개인정보, 실제 매출 예측을 사용하는 서비스가 아닙니다.
GS와의 공식 제휴·승인을 의미하지 않습니다. NVIDIA 공개 **합성 페르소나 원본 1,000개**를
사용하며, 기본 로컬 기준선과 선택적 **JEV 평가 API** 실행을 구분합니다. 실제 GS 추천 API는 연결하지 않습니다.

## 실행

필요 환경: Node.js 22 이상과 npm, WebGL을 지원하는 브라우저. 정적 미리보기에는 Python 3도 필요합니다.
저장소 루트에서 실행합니다.

```bash
cd demo
npm ci
npm test
npm start
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)을 엽니다. **로컬 기준선**은 API 키나 유료 서비스 없이 실행합니다.
이미 설치한 의존성은 `npm start`만으로 실행할 수 있습니다.
`npm start`는 `demo/server.mjs`의 로컬 Node 서버를 실행합니다. SDK 추가 설치 없이 Node의 `fetch`를 사용합니다.

## 선택적 JEV 연결과 검증 상태

`demo/.env.local`에 `AI_GATEWAY_API_KEY`를 안전하게 설정한 뒤 서버를 시작합니다.
키 값은 브라우저·채팅·로그·Git에 출력하지 않습니다. `.env*`는 Git에서 제외되고 서버 정적 파일 허용 목록에도 없습니다.
서버는 `127.0.0.1`에만 바인딩하고 동일 출처 요청만 받습니다. 배포용 인증 서버를 구현한 것은 아닙니다.

화면 기본값은 **로컬 기준선**입니다. 사용자가 JEV를 선택하면 실시간 관찰 모드로 전환하고
`typesafe-ai/jev`를 Vercel Gateway의 `/v1/evaluate`로 호출합니다. GPT, Chat Completions,
자동 재시도, 로컬 규칙으로의 자동 대체는 없습니다. 입점·목적지·매대 선택을 실제 응답으로 진행하며
응답 대기 동안 모든 시뮬레이션 시계를 멈춥니다. 일시 정지 중 도착한 응답은 재개 때 적용합니다.

호출 한도 기본값은 **서버 프로세스당 20회**(`JEV_MAX_CALLS`)이며 무제한 실행 예산이 아닙니다.
초기/설정 한도와 현재 남은 횟수는 별개입니다. `/api/status`의 `maxCalls`, `used`, `callsRemaining`으로
현재 상태를 확인하며, 실패한 상류 요청도 시도 횟수를 소비합니다. 한도 확대는 비용을 확인하고 명시적으로 결정해야 합니다.
한도 소진·HTTP 오류·응답 검증 실패 시 중단하며 다른 모델로 이어가지 않습니다.

현재 **실제 입점 평가 응답 스모크 테스트는 성공**했지만 상류 HTTP 429도 관측했습니다.
실제 입점→목적지→상품 집기→결제 전체 흐름은 검증 중이며, 1,000명 전체를 JEV로 끝까지 실행했다고 주장하지 않습니다.
모의 응답 자동 테스트와 실제 API 검증을 구분합니다. 인간 행동·실제 구매 정확도 벤치마크는 아직 없습니다.

## 데모 흐름

1. **하루 계산 후 비교**: 본사 표준안 / 재고 우선안 / 균형 후보안 / 신상품 탐색안을 아홉 점포에서 계산한 뒤 대표 방문을 재생합니다. 준비 계산 시간은 별도입니다. 장면 재생은 느리게·기본·빠르게로 조절하며 결과는 바뀌지 않습니다.
   터치·트랙패드의 좌우 스와이프, 마우스 드래그, 이전·다음 버튼 또는 페이지 점으로 다른 점포를 봅니다.
   모바일도 점포마다 후보 4개의 2×2 구성을 유지하고, 점포 묶음을 세로로 쌓습니다.
2. **실시간 관찰의 하루·배속·정지**: 점포당 잠재 고객 1,000명의 하루를 00:00–24:00까지 비교합니다.
   입장하지 않는 사람도 집계하며, 기본 32×입니다. UI의 1 / 4 / 16 / 32 / 128 / 900× 설정이
   이동·판단·보충·애니메이션·집계에 함께 적용됩니다. 카드 모션만 따로 늦추지 않습니다.
   처리 성능이 부족하면 실효 배속을 표시하며, 숫자만 앞서 계산하지 않습니다.
3. **카드 확대**: 선택한 모드의 3D 세계를 확대합니다. 요약은 원래 동시성이 아닌 대표 방문이며, 실시간 모드는 엔진 시각과 동기화됩니다. 닫기 또는 Escape로 전체 화면에 돌아옵니다.
4. **후보 비교**: 모의 결제액, 합성 원가를 뺀 매출총이익, 품절로 실패한 구매 시도를 봅니다.
5. **계획 승인**: 해당 후보의 24시간 실험이 끝나면 계획을 저장할 수 있습니다.
   점주 보기에는 승인한 스냅샷만 표시합니다. 저장은 이 브라우저의 localStorage이며 실제 인증·발주가 아닙니다.

같은 점포의 후보는 같은 초기 총재고·시드·잠재 고객 일정을 사용합니다.
매대 재고와 창고 재고는 별도이며, 보충 직원이 이동·진열을 마친 뒤 보유 물량만 매대로 옮깁니다.
계산원과 보충 담당자는 별도 인력이라는 데모 가정입니다. 자동 발주나 무한 재입고는 없습니다.
공간 혼잡·입장 거절·체류 시간·보충 지연은 후보별로 달라질 수 있습니다.
완료 전 매출만으로 우승 후보를 확정하지 않습니다.
기본 32×에서 24시간의 산술상 실행 시간은 45분입니다. 빠른 하루 비교용 900×는
산술상 96초이며, 실제 완료 시간은 계산·렌더링 성능에 따라 더 길 수 있습니다.

## 정적 배포용 파일

```bash
cd demo
npm ci
npm run build
npm run preview
```

`demo/dist`에 필요한 소스·에셋·Three.js 런타임을 복사합니다.
미리보기는 [http://127.0.0.1:4174](http://127.0.0.1:4174)입니다.
`dist` 내용만 정적 호스팅에 올릴 수 있으며, 빌드 과정은 실제 배포나 외부 API 호출을 수행하지 않습니다.
**정적 Vercel/기타 정적 호스팅은 로컬 기준선만 지원합니다.** JEV에는 별도 Node 백엔드가 필요하며
현재 로컬 전용 서버가 그대로 외부에 배포되었다고 주장하지 않습니다. 키를 정적 빌드에 포함하면 안 됩니다.
저장소 루트의 `index.html`은 기존 배포 연결 확인용 임시 페이지를 보존한 것입니다.

## 범위와 공개 파일

현재 앱은 가상 상품 24개와 NVIDIA의 `Nemotron-Personas-Korea` 원본 합성 레코드 1,000개를 사용합니다.
원본 UUID·상세 이야기·출처·리비전·라이선스를 보존합니다. CC BY 4.0 출처 표시는 위 자료에 있으며
예산·시간 가중치·카테고리 수치는 원본 관측값이 아니라 별도로 작성한 가정입니다.
기존 수작업 5개 프로필은 레거시 회귀 검사용이며 현재 1,000명의 정체성을 대신하지 않습니다.
전국 점포 기초조사는 [research/README.md](research/README.md)에 별도로 기록합니다.
실제 전국 점포 구조를 복제한 모델은 아닙니다. 원본 이야기만으로 실제 한국인의 행동을 재현했다고 볼 수 없습니다.
24시간 동안 잠재 고객 1,000명의 입장 여부를 평가하지만 시간대별 유동인구·입점률은 합성 가정입니다.
실제 수요로 보정한 매출 예측이나 실제 POS 매출이 아닙니다. 각 점포의 A/B/C/D는 같은 1,000명을
다른 배치로 재실험하므로 36개 카드의 사람 수를 합쳐 36,000명의 독립 고객이라고 해석하지 않습니다.
신상품 탐색안(D, 보라색)은 가상 신상품 5종을 함께 배치한 비교안이며, 우승 결과를 강제로 만들지 않습니다.
Smallville의 기억 검색·반성 루프, 실제 GS 추천 역추정, 신상품 자동 발주, 서버 인증은 구현 범위 밖입니다.

API 키·환경 파일·의존성 폴더·로컬 기획 노트는 공개하지 않습니다.
`demo/server.mjs`는 기본 로컬 실행과 선택적 JEV 평가 API를 제공합니다. 키가 없으면 JEV 호출을 거절합니다.
실제 판단 추적에는 입력 해시·요청 ID·모델·선택·확률·지연·실패 상태를 기록합니다.
모델이 자연어 이유를 생성한 것처럼 꾸미지 않으며, 선택 설명과 공간 관측값의 출처를 구분합니다.
`cd demo && npm test`는 모의 네트워크를 사용하며 실제 외부 모델을 호출하지 않습니다.
Blender 편집 파일은 로컬 메타데이터를 포함할 수 있어 제외하고, 재생성용 Python 스크립트와
런타임 GLB를 제공합니다. 생성된 상품 포장은 가상 상품이며 공식 GS 상품 이미지가 아닙니다.

Three.js는 MIT 라이선스 의존성입니다. 자체 코드에 별도 오픈소스 라이선스를 추가하지 않았으며,
이 저장소를 공개한 것만으로 GS의 상표·상품 이미지에 대한 권한이 부여되는 것은 아닙니다.
