# JEV 연결 검증 — 2026-09-22

## 현재 판정

JEV 호출 경로를 실제 엔진에 연결했고, **입장 판단의 실응답 적용**은 확인했다. 그러나 목적지 단계에서 Gateway가 HTTP 429 (`rate_limit_exceeded`)를 반환하여 **입장 → 탐색 → 구매 → 결제 전체 실호출 검증은 미완료**다. 따라서 JEV의 페르소나 이해력·구매 현실성을 통과했다고 표시하지 않는다.

엔드포인트는 [공식 Evaluation HTTP API](https://vercel.com/docs/ai-gateway/modalities/evaluation#http-api)의 `POST /v1/evaluate`, 모델은 `typesafe-ai/jev`이다. Chat Completions, GPT 대체, 자동 재시도, 로컬 자동 대체는 사용하지 않는다.

## 실제 요청과 관측

이번 작업에서 upstream 요청은 총 6회였다. 이 중 입장 응답 3회가 성공했고, 목적지 요청 3회가 실패했다. 목적지 실패의 첫 건은 일반 502로만 기록되었으며, 안전한 오류 진단을 추가한 나머지 두 건에서 upstream 429를 확인했다. 별도로 중복 정책 텍스트 때문에 로컬 요청 크기 제한에 걸린 413 한 건이 있었으나 upstream으로 전송되지 않았다. 중복 텍스트를 줄인 후 대상 목적지 입력은 39,783 bytes였다.

첫 성공 기록:

- 모델 및 실제 라우팅: `typesafe-ai/jev` / `typesafe-ai`
- 공개 합성 source UUID: `43a0673d920445ea868d45e4aa73abcc`
- 단계: `entry-context/1`, 선택: `enter`
- 입력 토큰: 6,349, 응답 토큰: 34, 왕복: 1,050ms
- Gateway 보고 비용: `0`, 당시 marketCost: `0.000266658` (서로 다른 필드이며 미래 가격이나 총비용 보장 아님)
- 입력 해시: `db3fe5b7939208e7bf3a238632bf6ee3904a4bec70d64ec37837cd5949de7ac8`

마지막 실패 기록:

- 단계: `destination-context/1`, upstream HTTP 429
- 오류 유형: `rate_limit_exceeded`, `Retry-After` 없음
- 오류 메시지의 제한된 키워드 분류: `rate`, `capacity`. 이 분류만으로 계정 할당량과 공급자 용량 중 정확한 원인을 확정할 수 없다.
- 요청 ID: `b464e8a0-c16a-4056-907d-ef1af8db2039`
- 응답이 없으므로 사용량·비용은 `null`이며 0으로 추정하지 않는다.

같은 거절을 반복하지 않고 실호출 검증을 중단했다. 20회 검증 상한 중 남은 14회는 실행하지 않았다. 실행 중 서버는 앞선 5회 사용을 제외한 한도 15, 현재 사용 1, 잔여 14로 유지했다. `.env.local`의 기본값은 새 서버 프로세스당 20이며 UI 초기화는 서버 사용량을 초기화하지 않는다.

## 구현·모의 검증으로 확인한 것

- 입장, 목적지, 매대 구매마다 원문 페르소나·현재 미션·기억·시간·허용 행동을 전달한다. 진열 판단에는 정확한 SKU 좌표, 이웃 상품, 재고, 신상품/트렌드 가정과 이벤트를 넣는다.
- 의미를 임의 생성한 설명 대신 실제 선택·확률분포·모델/라우팅·사용량·입력 SHA-256을 저장한다. JEV 선택 확률은 실측 구매 확률이 아니며, `noticed`는 엔진이 제공한 가시성이지 모델의 시선 예측이 아니다.
- API 대기 중 모든 세계의 논리 시계를 고정한다. 일시정지 중 도착한 응답은 보관하고, 재개 전에는 적용하거나 다음 호출을 시작하지 않는다. 초기화 후 낡은 응답/오류는 새 실행을 변경하지 않는다.
- 모델 응답의 모델 ID, 선택지, 확률분포, 입력 해시를 검증한다. 불법 선택·timeout·예산 소진·429는 실패 상태로 남기며 매출로 만들지 않는다.
- JEV 서버/클라이언트/세계 통합 테스트는 모의 provider로 전체 경로와 지연 불변성을 검사한다. 이 테스트를 실제 모델 품질 평가라고 부르지 않는다.

## 다시 검증하기

Gateway 제한이 해소된 뒤 잔여 호출 예산을 확인하고 **명시적으로** 실행한다. 대규모 1,000명 × 36안 실호출은 수행하지 않았다.

```sh
npm start
node scripts/verify-jev.mjs             # 기본 모의 검증, 외부 호출 없음
node scripts/verify-jev.mjs --live      # 실제 1회 요청
node scripts/verify-jev-world.mjs --live # 실제 최대 10회, 한 사람의 하루 연동 확인
```

서버 키는 Git 제외 `.env.local` 또는 환경변수에만 둔다. 이전에 채팅으로 공유된 키는 교체를 권장한다. HTTP로 `.env.local`/`server.mjs`를 요청하면 404이며 정적 빌드에는 키나 서버 코드가 포함되지 않는다.

최종적으로 사람다운 행동 정확도를 판정하려면 동의·이용권한이 있는 실제 구매/관찰 데이터나 독립 평가자의 정답이 필요하다. 공개 합성 페르소나와 자체 규칙을 서로 비교하는 것만으로 현실 타당성을 입증할 수 없다.
